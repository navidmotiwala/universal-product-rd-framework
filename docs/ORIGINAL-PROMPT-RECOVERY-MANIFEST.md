# Original Prompt Recovery and Publication Manifest

**Audit date:** 2026-10-30  
**Goal:** Determine which earlier Universal Product R&D prompts are published in full and which cannot be verified against their original source.

## Evidence standard

- **Exact source verified:** Complete original user-provided source text was available and published without intentional rewriting.
- **Reconstructed:** A new formulation derived from available context. It is not a verbatim reproduction.
- **Partial:** The original topic names or summaries are known, but full original prompt bodies were not available.
- **Not verified:** Cannot establish exact original wording or completeness from the currently accessible source material.
