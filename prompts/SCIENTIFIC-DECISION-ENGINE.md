# Scientific Product Decision Engine Prompt

For [PRODUCT] and [DECISION], compare the available options using scientific reasoning.

Define the decision, feasible alternatives, hard constraints, success metrics, downside guardrails, uncertainty, and decision deadline.

For each option estimate expected customer value, technical feasibility, commercial outcome, costs, risks, reversibility, and dependencies. Identify which estimates are evidence-backed and which are assumptions.

Propose experiments based on expected value of information. Use sensitivity analysis and scenario analysis to identify assumptions that could change the choice.

Recommend BUILD, IMPROVE, EXPERIMENT, BUY, PARTNER, DEFER, or REJECT. Explain the rationale, evidence, confidence, decision owner, review date, and trigger for reconsideration.
