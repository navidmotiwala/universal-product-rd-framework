# Authorized Hands-on Product Testing Prompt

Evaluate [PRODUCT] for [USE CASE] using only available and authorized access.

Before testing, state the environment, device, version, account permissions, sample inputs, and constraints.

Prepare test cases covering normal use, edge cases, failure recovery, accessibility, performance, security boundaries, and relevant integrations.

For each case record steps, expected result, actual result, evidence, severity, reproducibility, and limitations.

Do not perform destructive, invasive, or unauthorized security testing. Do not invent observations. If access is unavailable, provide an executable test plan clearly labeled NOT EXECUTED.

Deliver a test matrix, issue register, prioritized fixes, and retest plan.
